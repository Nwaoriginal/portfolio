Biography & Academic Philosophy

I am currently a 100-level undergraduate at MIVA Open University, specializing in Computer Science. My approach to learning centers on deep fundamentals: understanding not just how modern libraries operate, but how browser rendering engines parse HTML, how CSS layout algorithms calculate box geometry, and how JavaScript engines execute asynchronous tasks via the event loop.

When building software, I emphasize modular component design, clean self-documenting codebases, accessibility, and high visual standards. Through rigorous coursework in COS 106 and complementary subjects, I aim to build software that creates tangible real-world value.
